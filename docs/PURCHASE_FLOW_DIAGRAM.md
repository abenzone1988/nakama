# 购买系统流程图

## 🔄 完整购买流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                          第三方支付平台                               │
│                    (抖音/快手/其他支付渠道)                           │
└────────────────────────────┬────────────────────────────────────────┘
                             │ HTTP POST
                             │ /v1/purchase/notify
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   game_purchase.go::HandlePurchaseNotify            │
├─────────────────────────────────────────────────────────────────────┤
│  1️⃣  解析请求 (JSON/Form)                                           │
│  2️⃣  verifySiteID() - 验证应用ID                                    │
│  3️⃣  verifyOrderAmount() - 验证金额                                 │
│  4️⃣  verifyPurchaseSignature() - 验证签名                           │
│      └─ MD5(site+time+key+uid+order_money+cp_order_id)            │
└────────────────────────────┬────────────────────────────────────────┘
                             │ 验证通过
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│              game_purchase.go::processPurchaseDelivery              │
├─────────────────────────────────────────────────────────────────────┤
│  5️⃣  findUserByCustomID() - 查找用户                                │
│      └─ SELECT id FROM users WHERE custom_id = $1                 │
│                                                                       │
│  6️⃣  防重复检查                                                      │
│      └─ GetPurchaseByTransactionId(cp_order_id)                    │
│         ├─ 已存在: 返回成功 (幂等性) ✅                              │
│         └─ 不存在: 继续处理                                          │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│           game_purchase.go::recordThirdPartyPurchase                │
├─────────────────────────────────────────────────────────────────────┤
│  7️⃣  构建 storagePurchase 对象                                      │
│      └─ userID, productId, transactionId, rawResponse, etc.       │
│                                                                       │
│  8️⃣  调用 core_purchase.go::upsertPurchases()                       │
│      └─ INSERT INTO purchase ... ON CONFLICT DO UPDATE             │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│              game_purchase.go::deliverProductToUser                 │
├─────────────────────────────────────────────────────────────────────┤
│  9️⃣  根据商品ID执行发货逻辑                                          │
│      ├─ 方式1: UpdateWallets() - 更新虚拟货币                        │
│      ├─ 方式2: StorageWriteObjects() - 发放道具                     │
│      ├─ 方式3: Runtime.InvokeFunction() - 自定义逻辑                │
│      └─ 方式4: NotificationSend() - 发送通知                        │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                         返回 "SUCCESS"                               │
│                   (或错误消息: sign error等)                         │
└─────────────────────────────────────────────────────────────────────┘
```

## 🔐 签名验证流程

```
第三方平台端:
┌─────────────────────────────────────────────┐
│ 1. 收集参数:                                 │
│    site = "xjsmdyapp_android"              │
│    time = "1699171200"                     │
│    key = "0c373fedcec01cff88aacdb8d2e28dc2"│
│    uid = "user123"                         │
│    order_money = "6.00"                    │
│    cp_order_id = "CP20231105001"           │
│                                             │
│ 2. 拼接字符串:                               │
│    signStr = site + time + key + uid +     │
│              order_money + cp_order_id     │
│                                             │
│ 3. 计算MD5:                                  │
│    sign = md5(signStr).lowercase()         │
└────────────┬────────────────────────────────┘
             │
             │ 发送请求 (包含 sign)
             │
             ▼
Nakama服务器端:
┌─────────────────────────────────────────────┐
│ 1. 从请求中提取相同参数                       │
│                                             │
│ 2. 从配置中获取对应的 key                     │
│    key = SiteKeyMap[req.Site]              │
│                                             │
│ 3. 使用相同算法计算:                          │
│    calculatedSign = md5(signStr)           │
│                                             │
│ 4. 比较签名:                                 │
│    if calculatedSign == receivedSign {     │
│        // 验证通过 ✅                        │
│    } else {                                │
│        // 验证失败 ❌                        │
│        return "sign error"                 │
│    }                                       │
└─────────────────────────────────────────────┘
```

## 🔄 系统集成点总结

| 集成点 | 文件位置 | 功能 | 是否复用现有系统 |
|--------|---------|------|-----------------|
| 购买记录存储 | `core_purchase.go::upsertPurchases()` | 将订单保存到数据库 | ✅ 是 |
| 防重复检查 | `core_purchase.go::GetPurchaseByTransactionId()` | 检查订单是否已处理 | ✅ 是 |
| 查询订单列表 | `core_purchase.go::ListPurchases()` | 分页查询购买记录 | ✅ 是 |
| 控制台管理 | `console_purchase.go` | 后台管理接口 | ✅ 是 |
| 用户查找 | `game_purchase.go::findUserByCustomID()` | 根据第三方ID查找用户 | ❌ 新增 |
| 签名验证 | `game_purchase.go::verifyPurchaseSignature()` | 验证第三方签名 | ❌ 新增 |
| 发货逻辑 | `game_purchase.go::deliverProductToUser()` | 执行商品发放 | ❌ 新增 |

## 📊 性能考虑

```
             请求到达
                │
                ▼
         ┌──────────────┐
         │  签名验证     │  ← 快速过滤 (MD5计算 < 1ms)
         └──────┬───────┘
                │ 验证通过
                ▼
         ┌──────────────┐
         │  数据库查询   │  ← 使用索引 (transaction_id)
         │  检查重复     │    查询时间 < 5ms
         └──────┬───────┘
                │ 不重复
                ▼
         ┌──────────────┐
         │  插入记录     │  ← 单条INSERT (< 10ms)
         │  (upsert)    │
         └──────┬───────┘
                │
                ▼
         ┌──────────────┐
         │  执行发货     │  ← 可能耗时较长
         │  (可异步)    │    建议 < 100ms 或异步处理
         └──────┬───────┘
                │
                ▼
            返回成功
            
总响应时间目标: < 200ms (同步) 或 < 50ms (异步)
```

---

**图例说明**:
- `│` `─` `┌` `└` `┬` `├` : 流程连接线
- `▼` `▶` : 流程方向
- `✅` : 已实现/通过
- `❌` : 失败/新增功能
- `1️⃣` `2️⃣` : 步骤编号
