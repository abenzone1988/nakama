# 挑战赛配置格式说明

## 概述
本文档详细说明了挑战赛配置在Excel中的格式定义，包括字段说明、时间格式、持续时间计算等。

## Excel配置表格式

### 必需字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| id | string | 挑战赛唯一标识符 | "C001" |
| activity_id | string | 关联的活动ID | "summer_2024" |
| name | string | 挑战赛名称 | "夏季挑战赛第一期" |
| description | string | 挑战赛描述 | "夏季限时挑战活动" |
| start_date | string | 开始日期 | "2024-07-01" |
| start_time | string | 开始时间 | "10:00" |
| end_date | string | 结束日期 | "2024-07-02" |
| end_time | string | 结束时间 | "22:00" |
| duration_seconds | integer | 持续时间（秒） | 129600 |
| max_part | int | 最大人数 | 20 |
| status | integer | 状态（0:禁用, 1:启用） | 1 |

### 可选字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| reward_config | string | 奖励配置（JSON格式） | '{"first":{"gem":1000},"second":{"gem":500}}' |
| category | integer | 分类 | 1 |
| requirements | string | 参与要求（JSON格式） | '{"level":10,"vip":false}' |
| sort_order | integer | 排序方式（0:升序, 1:降序） | 1 |
| operator | string | 操作符 | "best" |

## 时间格式规范

### 日期格式
- **格式**: `YYYY-MM-DD`
- **示例**: `2024-07-01`、`2024-12-25`

### 时间格式
- **格式**: `HH:MM` (24小时制)
- **示例**: `10:00`、`22:30`、`00:00`

## 持续时间计算

系统会自动根据开始和结束时间计算活动持续时间：
- **公式**: `(结束日期 结束时间) - (开始日期 开始时间)`
- **示例**: 从 `2024-07-01 10:00` 到 `2024-07-02 22:00` = 36小时

### 实际使用示例

#### 示例1：周末挑战赛
- **开始**: 2024-07-01 10:00（周六上午10点）
- **结束**: 2024-07-02 22:00（周日晚上10点）
- **持续**: 36小时（129600秒）

#### 示例2：每日挑战赛
- **开始**: 2024-07-01 00:00（每天凌晨）
- **结束**: 2024-07-01 23:59（每天23:59）
- **持续**: 24小时（86400秒）

#### 示例3：长期挑战赛
- **开始**: 2024-07-01 00:00（月初）
- **结束**: 2024-07-31 23:59（月末）
- **持续**: 30天（2592000秒）

## 操作符说明

- **best**: 保留最佳分数
- **set**: 设置分数（覆盖）
- **incr**: 增加分数
- **decr**: 减少分数

## 在Nakama中的使用

### 1. 创建挑战赛

```go
// 从配置创建挑战赛
challenge, found := templateManager.GetTplChallenge().FindByKey("C001")
if found && challenge.IsActive() {
    // 创建Tournament
    err := TournamentCreate(ctx, logger, cache, scheduler, 
        challenge.ID, 
        true, // authoritative
        challenge.SortOrder, 
        getOperatorInt(challenge.Operator),
        "", // resetSchedule
        challenge.RewardConfig,
        challenge.Name,
        challenge.Description,
        challenge.Category,
        int(challenge.StartTimeUnix),
        int(challenge.EndTimeUnix),
        int(challenge.DurationSeconds),
        challenge.MaxParticipants,
        1000000, // maxNumScore
        false, // joinRequired
        true, // enableRanks
    )
}
```

### 2. 检查挑战赛状态

```go
// 检查是否可以参与
if challenge.CanJoin() {
    // 允许参与
}

// 获取剩余时间
remainingTime := challenge.GetRemainingTime()
```

### 3. 结算奖励

```go
// 在挑战赛结束时触发
if !challenge.IsActive() {
    // 处理奖励结算
    processRewards(challenge.ID, challenge.RewardConfig)
}
```

## 注意事项

1. **时间格式严格**: 必须严格按照指定格式，否则解析会失败
2. **时区一致性**: 确保所有时间都基于同一时区
3. **持续时间验证**: 系统会验证结束时间必须晚于开始时间
4. **数据验证**: 配置加载时会进行完整性验证
5. **JSON格式**: 奖励配置和参与要求必须是有效的JSON字符串
6. **性能考虑**: 建议合理设置最大参与人数，避免性能问题

## 错误处理

常见错误及解决方案：

1. **时间格式错误**: 检查日期时间格式是否正确
2. **时间逻辑错误**: 确保结束时间晚于开始时间
3. **JSON格式错误**: 验证奖励配置和参与要求的JSON格式
4. **缺少必需字段**: 确保所有必需字段都已填写
5. **数值范围错误**: 检查数值字段是否在合理范围内
